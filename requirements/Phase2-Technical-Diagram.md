# Phase 2 - Technical Diagram

## Objective

Prepare **one technical diagram** that represents the system proposed in Phase 1.

The diagram should show:

- the main system components
- how the components interact
- the main data / information flow
- the contract between important components

## Expected Content

Your diagram should include the relevant parts of your system, such as:

- users
- frontend / interface
- backend services
- databases
- AI / ML components
- external APIs or services
- data pipelines, if relevant


## Deadline

Week **13**.
